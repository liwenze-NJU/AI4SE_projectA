## 区域图例

| 区域 | 作用 | 优先级 |
|---|---|---|
| 标题（目标动作 mono） | 明确被审批的是什么 | 首要 |
| `[? 待审批]` 药丸 | 三重冗余标识审批态 | 首要 |
| 风险原因列表 | 解释为何需人工 | 首要 |
| 影响范围卡 | 量化副作用边界 | 次要 |
| 超时倒计时 | 演示超时机制 | 次要 |
| 三按钮 | 人工决策入口 | 首要 |
| 结果反馈区 | 闭环回灌前确认 | 三级 |

## 关键状态变体

### 按钮
`[默认]`：
```
┌──────────┐  ┌──────────────────┐  ┌──────────┐
│  批准    │  │  拒绝并停止       │  │  稍后    │
└──────────┘  └──────────────────┘  └──────────┘
   主(黑底白字)   危险(红底白字)        次(白底阴影边框)
```
`[焦点]`：聚焦按钮加 `--focus-ring` 2px `--accent`；首焦点=批准。
`[禁用]`：审批已提交后三按钮禁用（`--meta` + 0.5 透明）。

### 超时倒计时
`[运行]`：
```
[██████████░░░░░░░░] 剩余 00:18     --warn 填充递减 + mono 数字
```
`[将超时]`（最后 5s）：
```
[██░░░░░░░░░░░░░░░░] 剩余 00:04     转 --danger + ⚠ 图标 + 文字"即将超时"
```
`[reduced-motion]`：条不动，仅 mono 数字与文字递减；仍可读。

### 结果反馈区（提交后短暂出现）
`批准`：
```
┌──────────────────────────────────────────┐
│ [✓ ALLOW 已批准] 绿                     │   1.5s 后关闭模态
└──────────────────────────────────────────┘
```
`拒绝`：
```
┌──────────────────────────────────────────┐
│ [⊘ BLOCK 已拒绝] 红                     │   → 转入 P4（CANCELLED/FAILED）
└──────────────────────────────────────────┘
```
`超时`：
```
┌──────────────────────────────────────────┐
│ [◷ TIMEOUT 已超时] 灰                   │   → 依脚本继续或转 CANCELLED
└──────────────────────────────────────────┘
```
> reduced-motion 下结果反馈为静态文字药丸（无淡入淡出），仍清晰可读。

## 空状态
- 不适用：模态仅在有待审批动作时弹出，必含目标动作与至少一条风险原因。

## 错误状态 — 审批提交失败
```
┌─ 审批对话框 ──────────────────────┐
│ [? 待审批]                        │
│ write_file(mock://…/auth.py)      │
│ ...                               │
│ ─────────────────────────────────│
│ [✕ 提交失败] 红                   │   mono 诊断
│ 诊断：mock approve endpoint…      │
│                       [重试]      │   模态保持打开
└───────────────────────────────────┘
```

## 审批状态机（本模态即审批状态机）
```
待审批（默认） ──批准──→ 已批准 ──┐
            ├──拒绝──→ 已拒绝 ──┤──回灌 P2 轨迹──→ 关闭模态
            └──超时──→ 已超时 ──┘
```

## 完成状态
- 审批动作提交后，结果反馈药丸显示约 1.5s（reduced-motion 静态），随后模态关闭、焦点回 P2 轨迹最后一步。

## 键盘
- 打开：焦点首置"批准"。
- Tab：在对话框内循环（焦点陷阱）。
- Esc：=稍后/取消。
- Enter：执行当前焦点按钮。
