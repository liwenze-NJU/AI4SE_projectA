## 区域图例

| 区域 | 作用 |
|---|---|
| 教学引言区 | 建立 Agent=LLM+Harness 心智模型（次要优先级） |
| 场景卡三联 | 三个确定性入口 + 预期护栏结果钩子（首要优先级） |
| 预期护栏药丸 | 提前告知该场景将演示的治理结果 |
| `[MOCK角]` 角标 | 标注"确定性 Mock · 离线回放" |
| `[进入演示]` 按钮 | 进入 P2 仪表盘 |
| 底部提示 | mono 小字引导（三级） |

## 空状态
- 不适用：P1 始终展示三张预设场景卡。

## 审批 / 完成状态
- 不适用（P1 无审批环节；选中即进入 P2，P1 无自身完成态）。
