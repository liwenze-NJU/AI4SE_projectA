## 关键状态变体

### 水平步进器节点
- `[已完成]`：`[①INIT] ✓` 实心语义色 + 实线连线。
- `[激活/当前]`：`[⑤AWAIT●]` 描边语义色 + 节点放大 1.1× + 脉冲点（reduced-motion 关闭脉冲，仍由描边+大字+药丸表达）。
- `[未到达]`：`[⑥EXEC]` 空心 `--meta` + 虚线连线。
- `[终态分支]`：COMPLETED 主路径实线绿；FAILED/CANCELLED/LIMIT_REACHED 侧分支，各自色+图标+文字。

### 执行轨迹行
`[默认]`：
```
│ ● DECIDING     00:04  决定调用 write_file(auth.py)   │   --border-soft 行分隔
```
`[展开]`（工具调用展开行）：
```
│ ● DECIDING     00:04  决定调用 write_file(auth.py)   │
│   └─$ write_file(mock://workspace/src/auth.py)       │   mono 命令
│       入参：[MOCK] patch="+ validate input"          │   MOCK 角标
│       结果：[? 待审批]                                 │   结果药丸
```
`[失败行]`（场景 C 第一次失败）：

### 护栏决策三联卡
- `[命中 REQUEST_APPROVAL]`：`[? 待审批] ████` 高亮 2px 黄边 + 原因可见。
- `[未命中]`：`[✓ ALLOW]` / `[⊘ BLOCK]` 淡化（`--meta`）。

### 演示控件
- `[步进▶]` 默认次按钮；回放至终态时 `[禁用]`。
- `[⏸暂停]` 进入 AWAITING_APPROVAL 时自动激活（黑底白字）。
- `[↺重放]` 始终可用，重置回放至 INITIALIZING。

## 审批状态
- 进入 `AWAITING_APPROVAL`：回放自动暂停 → 中栏最后一步 `⏸ 等待审批` 黄药丸 → 右栏 REQUEST_APPROVAL 高亮 → **P3 模态弹出**（见 `03-approval-dialog.md`）。
- 批准/超时后：模态关闭，轨迹回灌 `[✓ ALLOW 允许]`（绿）或 `[◷ TIMEOUT 超时]`（灰），步进器继续。
- 拒绝后：轨迹回灌 `[⊘ BLOCK 阻止]`（红），状态机转 `CANCELLED/FAILED` → 自动进入 P4。
