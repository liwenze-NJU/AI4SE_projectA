## 区域图例

| 区域 | 作用 | 优先级 |
|---|---|---|
| 终态头条 + 药丸 | 一眼判定本次结局 | 首要 |
| mono 指标（耗时/步数/护栏计数） | 量化运行 | 三级 |
| 反馈闭环卡 | 复现"失败→反馈→改动作→通过"闭环 | 首要（场景 C） |

## 终态药丸变体（4 种）

```
✓ COMPLETED 已完成   绿      ✕ FAILED 已失败   红
◌ CANCELLED 已取消   灰      ⇪ LIMIT_REACHED 达到上限   黄
```
> 每种均 色 + 图标 + 中文文字 三重冗余；色盲场景靠图标与文字区分。

## 反馈闭环卡 — 段状态
- 每段：语义色边条（①红/②黄/③蓝/通过绿）+ 编号圆 + 药丸 + mono 时间戳。
- 箭头 `───→` 为 `--meta`，编号明确因果，不依赖动画。
- 场景 A/B 简化版：显示"本次未触发测试反馈闭环"（mono，`--meta`），或仅展示对应终态路径与护栏结果。

- 计数为 0 的卡淡化：`0  [⊘ BLOCK 阻止]  (红·零计数淡化 --meta)`。

## 空状态
- 无 Memory 条目（理论不发生）：
```
┌─ Memory 摘要面板 ─────────────────────────────────┐
│ 本次会话无 Memory 沉淀   （mono，--meta）         │
└────────────────────────────────────────────────────┘
```
- 非闭环场景反馈卡：显示简化版 mono `--meta` 提示。

## 错误状态
- 不适用（P4 为终态收束；若 Memory 解析失败，Memory 面板显示 `[✕ 摘要不可用]` 红 + mono 诊断，其余正常）。

## 审批状态
- 不适用（P4 不进行审批；但 Memory 摘要回显本次审批结果条目，如 `[已批准决策] write_file(auth.py) 已批准`）。

## 完成状态
- P4 即"完成态"页面本身。
- `[返回场景选择]` → P1；`[重放本场景]` → P2（重置回放）。
